# Cheeno (Godot 4.2)

بازی پازل بلوکی برای اندروید.

## اجرا

1. Godot 4.2 را نصب کن و پوشه‌ی `game/` را باز کن.
2. دکمه‌ی Run را بزن (یا با ماوس و لمس در پنجره تست کن).

## وضعیت فعلی (نسخه‌ی ۰.۱)

- صفحه‌ی ۸×۸ با سه قطعه‌ی تصادفی.
- کنترل: قطعه را لمس کن، بعد خانه‌ای را لمس کن.
- هر خط کامل = امتیاز + یک سکه (ذخیره‌ی محلی).
- `scripts/api.gd` کلاینت وردپرس است؛ هنوز به بازی وصل نشده.

## مراحل بعد

- کشیدن و رها کردن قطعه (drag and drop)
- ورود با افزونه‌ی `cheeno-wallet` (deep link `cheeno://auth`)
- همگام‌سازی سکه با سرور و خرید از وب‌سایت
- ساخت APK با GitHub Actions
